Regras de nome
Comeca com $, depois letra ou _. Case-sensitive: $Nome != $nome.
Tipagem dinamica
O tipo e definido em tempo de execucao e pode mudar. PHP 8 permite type hints para forcar tipos.

Operadores

Aritmeticos e atribuicao

$a = 10; $b = 3;
$a + $b;   // 13
$a % $b;   // 1  (resto)
$a ** $b;  // 1000 (potencia)
$a += 5;   // $a = $a + 5
$a++;      // incrementa 1

Concatenacao (string)

$nome = "Ana";
echo "Ola, " . $nome . "!";   // ponto concatena
$msg = "Bem-vindo, ";
$msg .= $nome;                 // concatena e atribui

Comparacao

5 == "5"    // true  (so valor)
5 === "5"   // false (valor + tipo)
5 != "5"    // false
5 !== "5"   // true
$a <=> $b   // spaceship: -1, 0 ou 1

Logicos

$idade >= 18 && $ativo
$status == 'a' || $status == 'p'
!$ativo
Use === , nao ==
Evita bugs sutis de comparacao de tipos diferentes.

for e while

// for: quando sabemos QUANTAS vezes repetir
for ($i = 1; $i <= 5; $i++) {
    echo "Volta $i<br>";
}

// while: repete ENQUANTO a condicao for verdadeira
$contador = 0;
while ($contador < 5) {
    echo "Contador: $contador<br>";
    $contador++;
}
for
Ideal para percorrer indices ou repetir N vezes.
while
Ideal quando o numero de repeticoes depende de uma condicao.

do-while e foreach

$senha = "";

}

Dica Para arrays, foreach e sempre mais legivel que for.

break, continue e lacos aninhados

// break: interrompe o laco imediatamente
foreach ($notas as $nota) {
    if ($nota < 0) break;
    echo $nota . "<br>";
}

// continue: pula para a proxima iteracao
for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 == 0) continue; // pula os pares
    echo $i . " ";
}

// Laco aninhado: tabuada de 1 a 3
for ($i = 1; $i <= 3; $i++) {
    for ($j = 1; $j <= 10; $j++) {
        echo "$i x $j = " . ($i * $j) . "<br>";
    }
}

Funcoes — definindo e reutilizando

function saudacao($nome) {
    return "Ola, $nome!";
}
echo saudacao("Bruno"); // Ola, Bruno!

// Parametro com valor padrao
function calcularMedia($n1, $n2, $n3 = 0) {
    return ($n1 + $n2 + $n3) / 3;
}

// Tipagem (PHP 8): parametros e retorno tipados
function somar(int $a, int $b): int {
    return $a + $b;
}

Boa pratica Tipar parametros e retorno evita bugs e documenta a funcao.

Arrays indexados e associativos

// Indexado: posicoes numericas 0, 1, 2...
$frutas = ["maca", "banana", "uva"];
echo $frutas[1]; // banana

// Associativo: chaves nomeadas (como um "dicionario")
$usuario = [
    "nome"  => "Ana Silva",
    "email" => "ana@email.com",
    "ativo" => true
];
echo $usuario["nome"]; // Ana Silva

// Array multidimensional (parecido com resultado de SELECT!)
$usuarios = [
    ["id" => 1, "nome" => "Ana"],
    ["id" => 2, "nome" => "Bruno"],
];
echo $usuarios[0]["nome"]; // Ana

Superglobais $_GET, $_POST e validacao

// processa.php — recebendo dados do GET
$busca = $_GET['busca'] ?? '';   // ?? evita erro se nao existir
echo "Voce buscou por: " . htmlspecialchars($busca);

// cadastro.php — recebendo dados do POST
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nome  = trim($_POST['nome'] ?? '');
    $email = trim($_POST['email'] ?? '');

    if ($nome === '' || $email === '') {
        echo "Preencha todos os campos!";
    } else {
        echo "Cadastrado: $nome ($email)";
    }
}
Nunca confie no usuario
Sempre valide e use htmlspecialchars() antes de exibir dados recebidos — protege contra XSS.
