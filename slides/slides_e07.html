O que e PDO?

PDO (PHP Data Objects) e uma extensao do PHP que fornece uma interface padronizada para acessar bancos de dados. Com PDO voce pode trocar MySQL por PostgreSQL mudando apenas uma linha.

Vantagens do PDO
  • Seguranca: prepared statements contra SQL Injection
  • Portabilidade: funciona com MySQL, PostgreSQL, SQLite, etc.
  • Orientado a objetos: excecoes com try/catch
  • Reutilizacao: mesma API para qualquer SGBD
mysqli vs PDO
  • mysqli: so MySQL, procedural ou OO
  • PDO: multi-banco, apenas OO, mais moderno
  • Recomendado usar PDO em projetos novos
Nunca concatene SQL com dados do usuario!
Sempre use prepare() + execute(). Concatenacao direta abre brechas de SQL Injection.

Conectando ao MySQL com PDO — Modelo db.class.php

A conexao e estruturada na classe db (db.class.php). A DSN define driver, host, banco, porta e charset, com ERRMODE_EXCEPTION nas opcoes.

<?php
class db {
    private $host='localhost', $user='root', $password='', $port='3306';
    private $dbname='db_pweb1_2026_1', $table_name, $conn;
    public function __construct($table_name) {
        $this->table_name = $table_name;
        $this->conn = $this->connect();
    }
    private function connect() {
        try { return new PDO(
            "mysql:host=$this->host;dbname=$this->dbname;port=$this->port;charset=utf8",
            $this->user, $this->password,
            [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
        ); } catch (PDOException $e) {
            die('Erro na conexao: ' . $e->getMessage());
        }
    }
    // CRUD prontos — todos usam prepared statements
    public function all() { /* SELECT * */ }
    public function find($id) { /* por id */ }
    public function findBy($c, $v) { /* por campo */ }
    public function store($d) { /* INSERT */ }
    public function update($id, $d) { /* UPDATE */ }
    public function delete($id) { /* DELETE */ }
    public function search($c1, $c2, $t) { /* LIKE */ }
    // Transacoes
    public function beginTransaction() { $this->conn->beginTransaction(); }
    public function commit() { $this->conn->commit(); }
    public function rollBack() { $this->conn->rollBack(); }
}

DSN mysql:host=localhost;dbname=db_pweb1_2026_1;port=3306;charset=utf8. Implementacao completa em db.class.php.

Prepared Statements

O banco pre-compila a query e depois insere os valores separadamente. Isso impede que dados maliciosos alterem a estrutura do SQL.

<?php
// SQL Injection se fizer assim (NAO FACA):
// $sql = "SELECT * FROM usuarios WHERE email = '$email'";

require_once "db.class.php";
$db = new db('usuarios');

// FORMA CORRETA: metodos da classe db ja usam prepared statements
$usuario = $db->findBy('email', $email);

// Insercao segura com store (monta INSERT com marcadores ?)
$db->store([
    'nome'  => $nome,
    'preco' => $preco
]);
findBy($campo, $valor)
Busca um registro por um campo qualquer usando ? (positional). Internamente faz prepare() + execute().
store($dados)
Insere um array associativo ['coluna' => 'valor']. Monta a query com marcadores ? automaticamente.

CRUD — Create e Read

<?php
require_once "db.class.php";
$db = new db('usuarios');

// ========== CREATE (INSERT) ==========
$db->store([
    'nome'  => "Maria",
    'email' => "maria@email.com",
    'senha' => password_hash("123456", PASSWORD_DEFAULT)
]);
// store() executa prepare() + execute() com marcadores ?

// ========== READ (SELECT) ==========
$usuarios = $db->all(); // retorna array de objetos (FETCH_CLASS)

foreach ($usuarios as $u) {
    echo $u->nome . " - " . $u->email . "<br>";
}
store($dados)
Recebe array associativo e insere no banco. Usa prepared statement com marcadores ?.
all()
Retorna todos os registros da tabela como array de objetos (FETCH_CLASS).

CRUD — Update e Delete

<?php
require_once "db.class.php";
$db = new db('usuarios');

// ========== UPDATE ==========
$db->update(5, [
    'nome'  => "Maria Silva",
    'email' => "maria.silva@email.com"
]);
// update() monta SET campo = ? e executa com prepared statement

// ========== DELETE ==========
$db->delete(5);

// ========== SELECT UNICO ==========
$usuario = $db->find(5); // retorna objeto ou false
if ($usuario) {
    echo $usuario->nome;
}
update($id, $dados) / delete($id) / find($id)
Todos usam prepared statements internamente. update() monta dinamicamente o SET a partir de um array associativo.

Try/Catch e Transacoes

Transacoes garantem que varias operacoes sejam atomicas: ou todas acontecem, ou nenhuma acontece (rollback). Use os metodos da propria classe db.

<?php
require_once "db.class.php";
$db = new db('contas');

$origem = $db->find(1);
$destino = $db->find(2);

try {
    $db->beginTransaction();

    // Debita da conta origem e credita na conta destino
    $db->update(1, ['saldo' => $origem->saldo - 100]);
    $db->update(2, ['saldo' => $destino->saldo + 100]);

    $db->commit(); // confirma tudo
    echo "Transferencia realizada!";
} catch (Exception $e) {
    $db->rollBack(); // desfaz tudo
    echo "Erro: " . $e->getMessage();
}
beginTransaction()
Inicia uma transacao. O autocommit e desligado temporariamente.
commit() / rollBack()
commit confirma as mudancas. rollBack desfaz em caso de erro.

O que e MVC?

MVC (Model-View-Controller) e um padrao de arquitetura que separa a aplicacao em tres camadas, facilitando manutencao e testes.

Model
Regras de negocio e acesso ao banco. Classes PHP que representam entidades e fazem CRUD.
View
Apresentacao. HTML/JSON que o usuario ve. Nao contem logica de negocio.
Controller
Intermediario. Recebe requisicoes, chama Models e devolve Views/JSON.

Fluxo de uma requisicao

Usuario → Controller → Model → Banco → Model → Controller → View/JSON → Usuario

Model — Acesso ao banco

O Model encapsula todas as operacoes de banco para uma entidade. Ele nao sabe se esta sendo usado por uma pagina web ou por uma API.

<?php
// models/Produto.php
class Produto {
    private db $db;

    public function __construct(db $db) {
        $this->db = $db;
    }

    public function listar(): array {
        return $this->db->all();
    }

    public function buscar(int $id): ?object {
        $dados = $this->db->find($id);
        return $dados ?: null;
    }

    public function criar(
        string $nome, float $preco, int $qtd
    ): void {
        $this->db->store([
            'nome'       => $nome,
            'preco'      => $preco,
            'quantidade' => $qtd
        ]);
    }

    public function excluir(int $id): void {
        $this->db->delete($id);
    }
}

Controller — O maestro

O Controller recebe a requisicao HTTP, valida dados, chama o Model e devolve a resposta formatada.

<?php
// controllers/ProdutoController.php
require_once "db.class.php";
require_once "models/Produto.php";
require_once "views/produto_json.php";

class ProdutoController {
    private Produto $model;

    public function __construct(db $db) {
        $this->model = new Produto($db);
    }

    public function listar(): void {
        $produtos = $this->model->listar();
        resposta(["sucesso" => true, "dados" => $produtos]);
    }

    public function buscar(int $id): void {
        $produto = $this->model->buscar($id);
        if ($produto) {
            resposta(["sucesso" => true, "dados" => $produto]);
        } else {
            resposta([
                "sucesso" => false,
                "erro" => "Produto nao encontrado"
            ], 404);
        }
    }
}

Roteamento basico com .htaccess

O roteamento direciona URLs amigaveis para o arquivo correto. O .htaccess redireciona tudo para um index.php central.

# .htaccess (na raiz do projeto)
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php?url=$1 [QSA,L]
<?php
// index.php — roteador central
require_once "db.class.php";
require_once "controllers/ProdutoController.php";

$url = $_GET['url'] ?? '';
$url = explode("/", trim($url, "/"));

$db = new db('produtos');
$controller = new ProdutoController($db);

if ($url[0] === "produtos" && empty($url[1])) {
    $controller->listar();
} elseif (
    $url[0] === "produtos" && is_numeric($url[1])
) {
    $controller->buscar((int)$url[1]);
} else {
    resposta(["erro" => "Rota nao encontrada"], 404);
}
/produtos
Lista todos os produtos (GET).
/produtos/5
Busca o produto com id 5 (GET).

O que e uma API REST?

API (Application Programming Interface) e um conjunto de regras que permite que dois sistemas se comuniquem. REST (Representational State Transfer) e um estilo arquitetural que usa o protocolo HTTP de forma padronizada.

Principios REST
  • Recursos: tudo e uma URL (/usuarios, /produtos)
  • Representacao: dados em JSON (ou XML)
  • Stateless: cada requisicao e independente
  • Cacheavel: respostas podem ser cacheadas
Por que JSON?
  • Leve e legivel para humanos e maquinas
  • Nativo em JavaScript (React Native)
  • PHP converte facil com json_encode / json_decode

Exemplo guiado — API em PHP

Vamos construir uma API completa para a entidade Produto usando o metodo HTTP para decidir a acao.

<?php
// api/produtos.php — endpoint unico
require_once "../db.class.php";
require_once "../models/Produto.php";

$db = new db('produtos'); $model = new Produto($db);
$metodo = $_SERVER['REQUEST_METHOD'];
$id   = $_GET['id'] ?? null;
$body = json_decode(file_get_contents("php://input"), true);

header("Content-Type: application/json");

switch ($metodo) {
    case 'GET':
        echo json_encode($id ? $model->buscar((int)$id) : $model->listar());
        break;
    case 'POST':
        $model->criar($body['nome'], $body['preco'], $body['qtd']);
        http_response_code(201);
        echo json_encode(["mensagem" => "Criado"]);
        break;
    case 'DELETE':
        $model->excluir((int)$id);
        echo json_encode(["mensagem" => "Removido"]);
        break;
    default:
        http_response_code(405);
        echo json_encode(["erro" => "Metodo nao permitido"]);
}

Testando com Postman / Insomnia

Postman e Insomnia sao clientes HTTP que permitem testar APIs sem precisar de um frontend. Essenciais para desenvolvimento backend.

Postman (gratuito)
  • Colecoes de requisicoes organizadas por pasta
  • Variaveis de ambiente (dev, prod, local)
  • Testes automaticos com scripts
  • Import/export de colecoes
Insomnia (gratuito)
  • Interface mais limpa e leve
  • Suporte a GraphQL e REST
  • Plugins e temas
  • Ideal para quem quer simplicidade

Como testar a API

  1. Abra o Postman/Insomnia e crie uma nova requisicao
  2. Escolha o metodo (GET, POST, PUT, DELETE)
  3. Digite a URL: http://localhost/api/produtos.php
  4. Para POST/PUT: va em Body → raw → JSON e envie:
    {"nome":"Teclado","preco":120.00,"qtd":10}
  5. Clique em Send e verifique o JSON de resposta
