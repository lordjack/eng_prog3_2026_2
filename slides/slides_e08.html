GET — Listar e Buscar por ID

<?php
// model/Produto.php
require_once __DIR__ . '/../config/db.class.php';

class Produto {
    private db $db;
    public function __construct() { $this->db = new db('produtos'); }

    public function listar(): array {
        return $this->db->all(); // SELECT * FROM produtos
    }
    public function buscar(int $id): ?object {
        $r = $this->db->find($id); // SELECT * WHERE id = ?
        return $r ?: null;
    }
}

// controller/ProdutoController.php
class ProdutoController extends Controller {
    private Produto $model;
    private ProdutoJsonView $view;
    public function __construct() {
        $this->model = new Produto();
        $this->view = new ProdutoJsonView();
    }
    public function listar(): void {
        $this->view->renderListar($this->model->listar());
    }
    public function buscar(int $id): void {
        $produto = $this->model->buscar($id);
        if($produto) $this->view->renderBuscar($produto);
        else          $this->view->renderErro('Produto nao encontrado', 404);
    }
}

POST — Criar com validacao basica

<?php
// controller/ProdutoController.php
public function criar(): void {
    $dados = $this->getDadosRequisicao(); // le e decodifica php://input

    if(empty($dados['nome']) || !isset($dados['preco']) || !isset($dados['quantidade'])) {
        $this->view->renderErro('Campos obrigatorios: nome, preco, quantidade', 400);
        return;
    }

    try {
        $this->model->criar([
            'nome' => $dados['nome'],
            'preco' => (float) $dados['preco'],
            'quantidade' => (int) $dados['quantidade'],
        ]);
        $this->view->renderCriar(); // 201 + mensagem padrao
    } catch(Exception $e) {
        $this->view->renderErro($e->getMessage(), 500);
    }
}

// model/Produto.php
public function criar($dados): void {
    $this->db->store($dados);
}
Validacao no Controller
Sempre valide antes de chamar o Model. A View (*JsonView) padroniza 400 Bad Request para dados invalidos e 500 para erros de banco.

Roteamento — GET e POST no index.php

<?php
// index.php — roteador central
require_once __DIR__ . '/controller/ProdutoController.php';

$url    = $_GET['url'] ?? '';
$url    = explode('/', trim($url, '/'));
$metodo = $_SERVER['REQUEST_METHOD'];
$controller = new ProdutoController(); // Model e View sao criados no proprio construtor

if($url[0] === 'produtos' && empty($url[1]) && $metodo === 'GET') {
    $controller->listar();
} elseif($url[0] === 'produtos' && is_numeric($url[1]) && $metodo === 'GET') {
    $controller->buscar((int) $url[1]);
} elseif($url[0] === 'produtos' && empty($url[1]) && $metodo === 'POST') {
    $controller->criar();
} else {
    $controller->rotaNaoEncontrada();
}
.htaccess

PUT — Atualizar com validacao

<?php
// controller/ProdutoController.php
public function atualizar(int $id): void {
    // valida existencia
    if(!$this->model->buscar($id)) {
        $this->view->renderErro('Produto nao encontrado', 404);
        return;
    }
    $dados = $this->getDadosRequisicao();
    if(empty($dados)) {
        $this->view->renderErro('Nenhum dado enviado para atualizacao', 400);
        return;
    }

    try {
        $this->model->atualizar($id, $dados);
        $this->view->renderAtualizar();
    } catch(Exception $e) {
        $this->view->renderErro($e->getMessage(), 500);
    }
}

// model/Produto.php
public function atualizar(int $id, array $dados): void {
    $this->db->update($id, $dados); // monta SET dinamicamente
}
update($id, $dados)
O metodo update da classe db monta o SET dinamicamente a partir do array. So nao atualiza o campo id.

Tratamento centralizado de erros

Em vez de repetir header()/http_response_code()/json_encode() em cada metodo, o projeto centraliza isso na classe Controller e nas Views *JsonView.

<?php
// controller/Controller.php
header('Content-Type: application/json; charset=utf-8');

class Controller {
    public function resposta(array $dados, int $status = 200): void {
        http_response_code($status);
        echo json_encode($dados, JSON_PRETTY_PRINT);
    }
}

// view/produto_json.php — toda *JsonView extends Controller
class ProdutoJsonView extends Controller {
    public function renderErro(string $erro, int $status = 400): void {
        $this->resposta(['sucesso'=>false, 'erro'=>$erro], $status);
    }
    // renderListar(), renderBuscar(), renderCriar()... seguem o mesmo padrao
}
Controller (base)
So sabe transformar um array PHP em resposta HTTP + JSON. Nao conhece regra de negocio nenhuma.
renderErro() nas Views
Cada *JsonView herda de Controller e padroniza o formato {sucesso, erro} ou {sucesso, dados} em todos os endpoints.

JOIN — Trazer dados relacionados

Quando buscamos um produto, queremos tambem o nome da sua categoria. Para um JOIN customizado, o Model precisa acessar a conexao PDO — adicione um getter em db.class.php.

<?php
// config/db.class.php — adicione este metodo publico
public function getConn() {
    return $this->conn;
}
<?php
// model/Produto.php — metodo com JOIN
public function buscarComCategoria(int $id): ?array {
    $sql = "SELECT p.*, c.nome AS categoria_nome
             FROM produtos p
             LEFT JOIN categorias c ON p.categoria_id = c.id
             WHERE p.id = ?";
    $stmt = $this->db->getConn()->prepare($sql);
    $stmt->execute([$id]);
    $r = $stmt->fetch(PDO::FETCH_ASSOC);
    return $r ?: null;
}

// model/Produto.php — listar por categoria
public function listarPorCategoria(int $catId): array {
    $sql = "SELECT * FROM produtos WHERE categoria_id = ?";
    $stmt = $this->db->getConn()->prepare($sql);
    $stmt->execute([$catId]);
    return $stmt->fetchAll(PDO::FETCH_ASSOC);
}
Acesso a conexao PDO
Prefira criar getConn(): PDO (metodo publico) a tornar a propriedade $conn publica diretamente.

Relacionamento N:M (Pedidos ↔ Produtos)

Um pedido pode ter varios produtos, e um produto pode estar em varios pedidos. Usamos uma tabela intermediaria (pivot).

-- Tabela intermediaria (pivot)
CREATE TABLE pedido_produto (
    pedido_id    INT,
    produto_id   INT,
    quantidade   INT DEFAULT 1,
    PRIMARY KEY (pedido_id, produto_id),
    FOREIGN KEY (pedido_id)  REFERENCES pedidos(id),
    FOREIGN KEY (produto_id) REFERENCES produtos(id)
);

-- JOIN para listar produtos de um pedido
SELECT p.nome, p.preco, pp.quantidade
FROM pedido_produto pp
JOIN produtos p ON pp.produto_id = p.id
WHERE pp.pedido_id = ?;

Busca avancada com findAllBy() e LIKE

A classe db possui o metodo findBy(), que retorna apenas o primeiro registro. Para buscar todos os registros que coincidem, usamos findAllBy().

<?php
// config/db.class.php — metodo para retornar varios registros
public function findAllBy($campo, $valor) {
    $sql = "SELECT * FROM $this->table_name WHERE $campo LIKE ?";
    $st = $this->conn->prepare($sql);
    $st->execute(["%$valor%"]);

    return $st->fetchAll(PDO::FETCH_CLASS);
}
<?php
// model/Produto.php — busca todos os produtos por campo
public function buscarPor(string $campo, $valor): array {
    return $this->db->findAllBy($campo, $valor);
    // Busca em qualquer campo permitido com LIKE '%valor%'
}

// controller/ProdutoController.php
private const CAMPOS_BUSCA_PERMITIDOS = ['nome', 'preco', 'quantidade'];

public function buscarPor(): void {
    $campo = $_GET['campo'] ?? '';
    $valor = $_GET['valor'] ?? '';

    if(!in_array($campo, self::CAMPOS_BUSCA_PERMITIDOS, true)) {
        $this->view->renderErro('Campo de busca invalido. Use: ' . implode(', ', self::CAMPOS_BUSCA_PERMITIDOS), 400);
        return;
    }
    if($valor === '') {
        $this->view->renderErro('Informe o parametro valor', 400);
        return;
    }

    $produtos = $this->model->buscarPor($campo, $valor);
    $this->view->renderListar($produtos); // retorna array (vazio ou cheio)
}

// index.php — rota de busca
elseif($url[0] === 'produtos' && ($url[1] ?? null) === 'buscar' && $metodo === 'GET') {
    $controller->buscarPor();
}
findAllBy()
Metodo da classe db que aplica LIKE '%valor%' em um campo e retorna array de objetos.
Query string
A busca usa GET /produtos/buscar?campo=nome&valor=Camisa. O termo vem por $_GET, nao pelo body.
Whitelist de campos
Nunca concatene nomes de colunas vindos da URL sem validar. Use uma lista de campos permitidos para evitar SQL injection.

Validacoes de dados — Regras de negocio

Validacoes garantem que apenas dados corretos cheguem ao banco. A pasta utils/ ja existe no projeto, mas ainda esta vazia — vamos criar Validador.php.

<?php
// utils/Validador.php (crie este arquivo)
class Validador {
    public static function min(string $valor, int $min): bool {
        return strlen($valor) >= $min;
    }
    public static function positivo(float $valor): bool {
        return $valor > 0;
    }
    public static function email(string $valor): bool {
        return filter_var($valor, FILTER_VALIDATE_EMAIL) !== false;
    }
}

// controller/ProdutoController.php — validacao completa (metodo criar)
require_once __DIR__ . '/../utils/Validador.php';
// ...
$erros = [];
if(!Validador::min($dados['nome'], 3))          $erros[] = "Nome: min 3 caracteres";
if(!Validador::positivo((float)$dados['preco'])) $erros[] = "Preco deve ser positivo";
if(!empty($erros)) {
    $this->view->renderErro(implode('; ', $erros), 400);
    return;
}
Lista de erros
Em vez de retornar um erro de cada vez, acumule todos em um array e junte com implode() na mensagem. O frontend recebe o feedback completo de uma vez.
