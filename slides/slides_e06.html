O que e uma classe?

Uma classe e um molde que define como um objeto deve ser. Ela agrupa atributos (dados) e metodos (comportamentos) em uma unica estrutura.

<?php
class Produto {
    // Atributos (propriedades)
    public string $nome;
    public float $preco;
    public int $estoque;

    // Metodo (comportamento)
    public function exibir(): void {
        echo "$this->nome - R$ $this->preco";
    }
}
class
Palavra-chave que define o molde do objeto.
$this
Referencia ao proprio objeto dentro da classe.

Construtor: inicializando o objeto

O construtor e um metodo especial chamado automaticamente ao criar o objeto com new. Ele garante que o objeto nasce com dados validos.

<?php
class Produto {
    public string $nome;
    public float $preco;
    public int $estoque;

    // Construtor (PHP 8+ com property promotion)
    public function __construct(
        string $nome,
        float $preco,
        int $estoque = 0
    ) {
        $this->nome    = $nome;
        $this->preco   = $preco;
        $this->estoque = $estoque;
    }
}

$p = new Produto("Teclado", 120.00, 15);
echo $p->nome; // Teclado
__construct
O nome do construtor em PHP e sempre __construct (dois underlines).

Property Promotion (PHP 8)

PHP 8 permite declarar atributos diretamente no construtor, reduzindo codigo repetitivo:

<?php
class Produto {
    public function __construct(
        public string $nome,
        public float $preco,
        public int $estoque = 0
    ) {}
}

// Mesmo resultado, menos codigo
$p = new Produto("Monitor", 899.90);
echo $p->nome;    // Monitor
echo $p->estoque; // 0 (padrao)
Vantagem
Menos boilerplate. Atributo e inicializacao no mesmo lugar.
Restricao
So funciona no construtor. Nao pode ter logica extra no corpo (a menos que necessario).

Getters e Setters

Metodos controladores que permitem acesso seguro aos atributos privados, com validacao e regras de negocio.

<?php
class Produto {
    private string $nome;
    private float $preco;

    public function __construct(string $nome, float $preco) {
        $this->setNome($nome);
        $this->setPreco($preco);
    }

    public function getNome(): string {
        return $this->nome;
    }

    public function setNome(string $nome): void {
        if (strlen($nome) < 3) {
            throw new Exception("Nome muito curto");
        }
        $this->nome = $nome;
    }

    public function getPreco(): float {
        return $this->preco;
    }

    public function setPreco(float $preco): void {
        if ($preco < 0) {
            throw new Exception("Preco nao pode ser negativo");
        }
        $this->preco = $preco;
    }
}

Propriedades tipadas e readonly (PHP 8.1+)

<?php
class Usuario {
    // readonly: so pode ser escrito no construtor
    public readonly int $id;
    public string $nome;
    private string $senha;

    public function __construct(int $id, string $nome, string $senha) {
        $this->id    = $id;    // OK: primeira e unica atribuicao
        $this->nome  = $nome;
        $this->senha = password_hash($senha, PASSWORD_DEFAULT);
    }

    public function verificarSenha(string $senha): bool {
        return password_verify($senha, $this->senha);
    }
}

$u = new Usuario(1, "Ana", "123456");
echo $u->id;      // 1
// $u->id = 2;    // ERRO! readonly nao pode ser alterado
Type hints
Forcam tipos em atributos, parametros e retornos. Evitam bugs de tipo.
readonly
Imutavel apos a construcao. Ideal para IDs, CPFs, datas de criacao.

Heranca com extends

Uma classe filha herda atributos e metodos da classe pai, podendo adicionar ou sobrescrever comportamentos.

<?php
class Animal {
    protected string $nome;

    public function __construct(string $nome) {
        $this->nome = $nome;
    }

    public function falar(): string {
        return "...";
    }
}

class Cachorro extends Animal {
    public function falar(): string {
        return "$this->nome diz: Au au!";
    }

    public function latir(): string {
        return "AU AU!";
    }
}

$dog = new Cachorro("Rex");
echo $dog->falar();  // Rex diz: Au au!

parent:: e sobrescrita (override)

Use parent:: para acessar o metodo da classe pai dentro da classe filha.

<?php
class Funcionario {
    protected string $nome;
    protected float $salario;

    public function __construct(string $nome, float $salario) {
        $this->nome    = $nome;
        $this->salario = $salario;
    }

    public function calcularBonus(): float {
        return $this->salario * 0.10;
    }
}

class Gerente extends Funcionario {
    public function calcularBonus(): float {
        // Chama o metodo da classe pai + adicional
        return parent::calcularBonus() + 500;
    }
}

$g = new Gerente("Carla", 5000);
echo $g->calcularBonus(); // 1000 (500 + 500)
Sobrescrita
O metodo filha deve ter a mesma assinatura (ou compativel com covariancia/contravariancia) da pai.

Classes abstratas

Uma classe abstrata nao pode ser instanciada diretamente. Serve de modelo para outras classes.

<?php
abstract class Pessoa {
    protected string $nome;

    public function __construct(string $nome) {
        $this->nome = $nome;
    }

    // Metodo concreto (com implementacao)
    public function getNome(): string {
        return $this->nome;
    }

    // Metodo abstrato (sem implementacao)
    abstract public function getTipo(): string;
}

class Aluno extends Pessoa {
    public function getTipo(): string {
        return "Aluno: $this->nome";
    }
}

class Professor extends Pessoa {
    public function getTipo(): string {
        return "Professor: $this->nome";
    }
}

$a = new Aluno("Joao");
echo $a->getTipo(); // Aluno: Joao

Polimorfismo em acao

Polimorfismo significa "muitas formas". Objetos de classes diferentes respondem ao mesmo metodo de formas distintas.

<?php
class PagamentoCartao {
    public function processar(): string {
        return "Processando no cartao...";
    }
}

class PagamentoPix {
    public function processar(): string {
        return "Gerando QR Code do Pix...";
    }
}

// Mesmo metodo, comportamentos diferentes
$pagamentos = [new PagamentoCartao(), new PagamentoPix()];
foreach ($pagamentos as $p) {
    echo $p->processar() . "
";
}
Por que usar?
Permite tratar objetos diferentes de forma uniforme. Essencial para APIs que recebem varios tipos de entidades.

Interfaces: contratos de comportamento

Uma interface define o que uma classe deve fazer, mas nao como fazer. Qualquer classe que a implementar deve cumprir o contrato.

<?php
interface Pagavel {
    public function pagar(float $valor): bool;
    public function gerarComprovante(): string;
}

class Boleto implements Pagavel {
    public function pagar(float $valor): bool {
        // logica do boleto
        return true;
    }

    public function gerarComprovante(): string {
        return "Comprovante de boleto";
    }
}

class CartaoCredito implements Pagavel {
    public function pagar(float $valor): bool {
        // logica do cartao
        return true;
    }

    public function gerarComprovante(): string {
        return "Comprovante de cartao";
    }
}

Type hints e tipagem de retorno

PHP permite tipar parametros e retornos, garantindo que apenas objetos compativeis sejam aceitos.

<?php
interface Notificavel {
    public function enviar(string $mensagem): void;
}

class Notificador {
    // Aceita QUALQUER objeto que implemente Notificavel
    public function notificar(Notificavel $canal, string $msg): void {
        $canal->enviar($msg);
    }
}

class Email implements Notificavel {
    public function enviar(string $mensagem): void {
        echo "Email enviado: $mensagem
";
    }
}

class Sms implements Notificavel {
    public function enviar(string $mensagem): void {
        echo "SMS enviado: $mensagem
";
    }
}

$n = new Notificador();
$n->notificar(new Email(), "Ola!");
$n->notificar(new Sms(), "Ola!");
Type hint de interface
O parametro Notificavel $canal aceita qualquer classe que implemente a interface. Isso e polimorfismo com seguranca de tipos.
